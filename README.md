# OKHU - University Recommendation Platform

A VirusTotal-inspired web application for university recommendations and search, built with HTML, CSS, and JavaScript.

## Features

### 🎓 Recommender Tab
- **CV Upload**: Upload your resume for personalized recommendations
- **Transcript Upload**: Submit academic transcripts for analysis
- **Country Selection**: Choose your preferred study destination
- **Education Language**: Select your preferred language of instruction
- **GPA Input**: Enter your current GPA (0.0-4.0 scale)
- **Speciality Selection**: Choose your field of study
- **Language Certificate Upload**: Upload language proficiency certificates
- **AI-Powered University Recommendations**: Get personalized university suggestions using advanced Groq AI analysis
- **AI-Powered Scholarship Discovery**: Find relevant scholarships including university-specific, country-level, regional, and international scholarships

### 🔍 Search Tab
- **University Search**: Search for any university worldwide using AI-powered search
- **AI-Generated Details**: View comprehensive university information including:
  - University overview and history
  - Country information
  - Application requirements (GPA, test scores, deadlines, tuition)
- **AI-Generated Community Insights**: Access realistic social media content including:
  - Reddit-style discussions about the university
  - Twitter and Instagram mentions
  - Student reviews and experiences

## Setup Instructions

### 1. Get Your Groq API Key
1. Visit [Groq Console](https://console.groq.com/)
2. Sign up for an account
3. Create a new API key
4. Copy your API key

### 2. Configure the Application
1. Open `script.js`
2. Find the line: `GROQ_API_KEY: 'YOUR_GROQ_API_KEY_HERE'`
3. Replace `YOUR_GROQ_API_KEY_HERE` with your actual Groq API key

### 3. Run the Application
1. Open `index.html` in a web browser
2. Or serve it using a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```

## Usage

### Getting University & Scholarship Recommendations
1. Click on the **Recommender** tab
2. Fill out the form with your information:
   - Upload your CV and transcript
   - Select your country preference
   - Choose your education language
   - Enter your GPA
   - Select your field of study
   - Upload language certificates (optional)
3. Click **Get Recommendations**
4. View personalized university suggestions with match scores
5. Browse available scholarships including:
   - University-specific scholarships
   - Country-level government scholarships
   - Regional scholarships (EU, ASEAN, etc.)
   - International scholarships (Fulbright, Chevening, etc.)
   - Field-specific and merit-based scholarships

### Searching for Universities
1. Click on the **Search** tab
2. Enter a university name in the search box
3. Click **Search** or press Enter
4. Browse the **Details** tab for official information
5. Check the **Community** tab for social media insights

## Customization

### AI Model Configuration
The application uses Groq's Llama 3.1 model by default. You can modify the model in `script.js`:

```javascript
// In getUniversityRecommendations() and searchUniversity() functions
model: 'llama-3.1-8b-instant' // Change to other available models
```

Available Groq models:
- `llama-3.1-8b-instant` (default - fast and efficient)
- `llama-3.1-70b-versatile` (slower, more capable)
- `llama-3.1-405b-preview` (most capable, slower)

### Styling Customization
Modify `styles.css` to change:
- Color scheme
- Typography
- Layout
- Animations

## Troubleshooting

### Common Issues

1. **API Key Not Working**
   - Ensure your Groq API key is correct and active
   - Check if you have sufficient API credits
   - Verify the API key has the correct permissions

2. **File Upload Not Working**
   - Ensure you're serving the files from a web server (not opening directly in browser)
   - Check browser console for any CORS errors

3. **AI Responses Not Loading**
   - Check your internet connection
   - Verify the Groq API key is properly configured in `script.js`
   - Check browser console for API errors
   - Ensure you have sufficient Groq API credits

4. **Slow Response Times**
   - AI processing can take 5-15 seconds depending on complexity
   - Consider switching to a faster model like `llama3-8b-8192` for quicker responses
